# Travel Compass 🧭

A responsive travel website showcasing 7 popular destinations in India: Agra, Jaipur, Goa, Kerala, Leh-Ladakh, Varanasi and Mysore.

Built as my Semester 1 Web Development (WSD) project at Christ University to practise HTML, CSS and JavaScript.

**Live demo:** https://vjnandan.github.io/travel-compass/

## Features
- Responsive layout using Bootstrap 5 and custom CSS
- Destination sections with images and attraction tables
- Trip booking form with JavaScript validation (name, email, 10-digit mobile, destination)
- Destination image preview before booking
- Date picker that blocks past dates
- In-page navigation, travel guide and travel tips

## Tech Stack
HTML5, CSS3, JavaScript (ES6), Bootstrap 5
